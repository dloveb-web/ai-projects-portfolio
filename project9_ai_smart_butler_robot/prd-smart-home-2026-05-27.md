## 1. 产品目标

| # | 目标 | 衡量方式 | 成功标准 |
|---|------|----------|----------|
| G1 | **让隐私回归家庭** — 成为市场上唯一真正做到数据不出户的AI家庭伙伴 | 本地处理率、用户隐私感知度 | 本地处理率 ≥ 95%；80% 用户能主动说出"数据在家里" |
| G2 | **让每个家人都被看见** — 通过多人格零感知切换，让老人、中年人、孩子各自获得最适合的交互体验 | 人格识别准确率、跨用户满意度 | 面部+声纹联合识别准确率 ≥ 99%；三类用户 NPS 均 ≥ 40 |

## 2. 用户故事

### US-01 老人 · 吃药闭环
> 张奶奶，78岁，独居。每天需服用降压药和降糖药。机器人定时提醒"张奶奶，该吃降压药了"，张奶奶取药后说"吃了"，机器人确认并记录。如果15分钟未确认，机器人主动追问；如果30分钟仍未确认，通知子女。

### US-02 老人 · 沉默报警
> 李爷爷，82岁，腿脚不便。某天凌晨去卫生间时不慎跌倒，无法按按钮呼救。机器人通过摄像头检测到异常姿态（地面躺卧），5秒内发起紧急求助，自动拨打子女电话并发送现场画面。

### US-03 中年人 · 高效助手
> 王先生，45岁，互联网从业者。下班回家说"帮我打开客厅灯、空调调到26度、播放轻音乐"，机器人一次性理解多意图指令，并行执行，2秒内完成全部操作。

### US-04 中年人 · 情绪舒缓
> 赵女士，40岁，全职妈妈。连续带娃一周后，对机器人叹气说"好累"。机器人识别到疲劳情绪，主动回应"辛苦了，要不要听会儿白噪音休息一下？"并在确认后调暗灯光、播放白噪音。

### US-05 孩子 · 趣味学习
> 小明，7岁，小学二年级。对机器人说"我想听恐龙的故事"，机器人切换为趣味伙伴人格，用生动的语气讲恐龙故事，并在故事结束后自然地问"你知道霸王龙的前爪为什么那么短吗？"引导好奇心。

### US-06 孩子 · 分级透明
> 小美，12岁，青春期。向机器人倾诉"今天和好朋友吵架了，很伤心"。机器人识别为私密级内容，提供即时情绪陪伴，不通知家长具体内容，但在家长端匿名呈现"孩子近期情绪波动趋势"。

### US-07 全家 · 零感知切换
> 王家三代同堂。爷爷走近时，机器人自动识别面部，切换为长辈陪伴型人格，语速放慢、字体放大；孙子跑来时，0.5秒内切换为趣味伙伴型，语气活泼。两人都不曾察觉"切换"这个动作的存在。

### US-08 全家 · 远程看护
> 王先生出差在外，通过手机APP查看家中父亲的当日活动摘要（起床时间、吃药情况、活动量），发现父亲今天比平时晚起了1小时且未按时吃药，随即通过机器人与父亲通话确认情况。

## 3. 用户研究洞察摘要

> 来源：瑞思（Reese）· 用户研究员

| # | 洞察 | 设计含义 |
|---|------|----------|
| I1 | **"闭环"是核心**：提醒≠执行，用户需要的是"提醒→确认→记录→异常升级"全链路 | 所有提醒类功能必须设计闭环，不允许停留在"提醒了就算完成" |
| I2 | **"沉默报警"是刚需**：老人跌倒、长时间无活动等异常需要系统主动发现 | 紧急求助不能只依赖"用户主动触发"，必须支持被动检测模式 |
| I3 | **语音"二次失败即放弃"**：老人对技术失败容忍度极低 | 语音识别必须做到1-2次成功；超过2次失败必须降级为屏幕/物理按键交互 |
| I4 | **情绪识别的价值在于"然后呢"**：识别到情绪后必须有响应行动 | 每种可识别情绪必须绑定至少一种响应策略（详见第8节映射表） |
| I5 | **多人格零感知切换**：基于面部/声纹自动适配，用户不应感知到"切换"动作 | 切换过程必须无UI提示、无延迟感，响应时间 < 0.5秒 |
| I6 | **"告密者困境"**：亲子互动需要分级透明机制 | 设计安全级/成长级/私密级三级透明机制（详见第9节） |
| I7 | **本地部署的"信任悖论"**：用户需要的是"可感知的安全感" | 隐私保护不能只做技术实现，必须设计可感知的隐私状态指示（如物理指示灯） |

## 4. 竞品对比摘要

> 来源：竞析 · 竞品分析师

### 市场定位

我方处于**"高功能丰富度 + 高情感陪伴深度"**的空白区域，是唯一同时横跨工具理性与情感陪伴两大价值域的产品。

### 差异化优势（5大机会）

| # | 差异化点 | 现状 |
|---|----------|------|
| D1 | **隐私守护者定位** | 2025年3月Amazon取消Echo本地处理后，主流智能音箱全面云端化，"本地部署"成为断层式领先的核心壁垒 |
| D2 | **全家AI多人格适配** | 竞品均为单一交互模式，无人做"一人一AI"的自动适配 |
| D3 | **有灵魂的主动关怀** | 竞品均为被动响应式，无人做"识别→判断→主动行动"的关怀闭环 |
| D4 | **可移动的看护者** | 固定设备无法实现跌倒检测后的近距离确认、跟随式陪伴等场景 |
| D5 | **银发经济赛道卡位** | 竞品聚焦年轻人，银发市场存在结构性空白 |

### 关键风险

| # | 风险 | 应对思路 |
|---|------|----------|
| R1 | 生态从零起步 | P0聚焦自有闭环能力，P1/P2逐步接入第三方 |
| R2 | 品牌认知为零 | 首发聚焦银发群体口碑，采用社区+KOL渗透 |
| R3 | 续航挑战 | M1验证24h续航目标，备用方案为充电桩自动回充 |
| R4 | 价格心理门槛 | 需通过用户测试确定甜蜜点，考虑分期/租赁模式 |
| R5 | 巨头跟进风险 | 速度是关键，6个月先发窗口期 |

```
└─────────────────────────────────────────────────────────────┘
```

**验收标准**：
- [ ] 定时提醒准时触发，误差 ≤ ±1分钟
- [ ] 闭环全链路可追溯（提醒→确认→记录→升级，每步有据可查）
- [ ] 15分钟未确认自动二次提醒
- [ ] 30分钟未确认自动通知紧急联系人
- [ ] 子女30秒内收到APP推送，未读则自动拨打

## 8. 情绪-响应映射表

| 情绪 | 检测信号 | 响应策略 | 具体行动 | P级 |
|------|----------|----------|----------|-----|
| **开心** | 语音语调上升+面部笑容 | 共鸣强化 | 用匹配的愉快语气回应；记录"今日好心情"到健康日志；适时分享相关趣闻 | P1 |
| **悲伤** | 语音低沉+面部表情下垂 | 温暖陪伴 | 语气转温和关怀；主动询问"要不要聊聊？"；如持续2小时+低落，建议听音乐/休息；匿名记录情绪趋势 | P1 |
| **焦虑** | 语速加快+词汇重复+面部紧张 | 稳定安抚 | 语速放慢回应；提供具体可执行的建议（如"试试深呼吸"）；拒绝过度追问；如持续升级，建议联系家人 | P1 |
| **愤怒** | 音量升高+面部表情紧绷 | 冷处理+疏导 | 不反驳不争辩；语气平静简短；等待情绪降温后温和询问原因；不在此情绪下执行重要操作（如购买/删除） | P1 |
| **疲劳** | 语速慢+叹气+面部倦怠 | 主动减负 | 主动简化交互（"要帮忙设个闹钟休息吗？"）；调暗灯光/播放白噪音；减少主动对话频率；如持续，建议休息/就医 | P1 |
| **恐惧** | 音调突高+面部惊恐+行为异常 | 安全确认 | 立即询问"怎么了？需要帮助吗？"；如为安全威胁（火/烟/入侵），触发紧急求助；如为非安全恐惧，提供陪伴安抚 | P1 |
| **困惑** | 重复询问+长时间沉默+面部迷茫 | 简化引导 | 换用更简单的语言重新解释；提供选择题而非开放式提问；屏幕同步显示关键信息；学习该用户的困惑模式以提前预防 | P1 |

**设计原则**：
1. **绝不空识别**：识别到情绪后必须有至少1项响应行动
2. **响应分级**：轻度情绪→简短回应；中度情绪→主动建议；重度/持续情绪→联动家人/医疗
3. **隐私保护**：情绪记录默认私密级，仅匿名趋势可被家人查看
4. **避免过度**：不每句话都做情绪分析，仅在显著情绪波动时触发

## 9. 分级透明机制

> 解决"告密者困境"：机器人是孩子的朋友，也是家长的安全网，但不应成为"告密者"。

| 级别 | 定义 | 示例 | 家长可见内容 | 孩子感知 |
|------|------|------|-------------|----------|
| **安全级** | 涉及人身安全的风险事件 | 自伤倾向、遭受霸凌、危险行为模仿、陌生人接触 | **立即通知**：具体事件+上下文+建议应对 | 知道家长会被告知（机器人温和说明"我要告诉爸爸妈妈，因为他们能帮你"） |
| **成长级** | 需要家长引导但非紧急的成长话题 | 学习困难、社交困惑、价值观偏差、不良信息接触 | **征得同意后分享**：询问孩子"这个情况可以让爸爸妈妈知道吗？"；孩子同意则详细分享；不同意则匿名呈现趋势 | 有选择权；知道机器人会询问自己 |
| **私密级** | 孩子的个人情感和隐私 | 情绪波动、朋友间的矛盾、个人烦恼、秘密 | **仅匿名趋势**：如"本周情绪波动指数较上周上升20%"，无具体内容 | 知道对话内容不会被直接转述；可通过趋势了解自己 |

### 机制设计细节

**安全级触发判定**：
- 关键词+语义分析（自伤、危险行为等高置信度触发）
- 人工校准：安全级关键词列表需经过儿童心理专家审核
- 误判保护：如触发安全级但孩子否认，记录但不强制通知，人工复核

**成长级征询流程**：
```
孩子表达成长级话题 → 机器人提供即时陪伴/建议 → 
对话结束后温和询问"这个事情，你想让爸爸妈妈知道吗？" →
├── 同意 → 告知孩子将分享哪些内容 → 生成家长端摘要
└── 不同意 → 尊重选择 → 记录为私密级 → 匿名趋势可呈现
```

**私密级趋势呈现**：
- 以周/月为单位呈现情绪、社交活跃度、兴趣变化等趋势
- 不包含任何具体对话内容或可识别的事件细节
- 家长端标注"基于匿名数据，具体内容需与孩子沟通"

## 10. Non-goals（明确不做什么）

| # | 不做什么 | 原因 |
|---|----------|------|
| NG-1 | **不做全屋智能中控** | 本产品定位为AI伙伴而非智能中控，不做HomeAssistant式全设备管控平台 |
| NG-2 | **不做医疗诊断** | 健康检测仅做监测和异常提醒，不做诊断、不做处方建议，避免医疗责任风险 |
| NG-3 | **不做视频监控存储** | 摄像头仅用于实时识别（面部/姿态/情绪），不做视频录制和云端存储 |
| NG-4 | **不做社交平台** | 不做用户间社交功能，不做社区/论坛，聚焦家庭内部场景 |
| NG-5 | **不做儿童教育课程体系** | 提供趣味知识问答和启蒙引导，不做系统性课程、不做学科辅导 |
| NG-6 | **不做开放应用市场** | 技能更新走官方审核通道，不做第三方开发者自由上架的开放市场 |
| NG-7 | **不支持户外使用** | 产品定位为室内家庭使用，不做防水/防摔/户外导航 |
| NG-8 | **不做宠物专属功能** | 避障需识别宠物，但不做宠物专属交互/喂食/监测功能 |
