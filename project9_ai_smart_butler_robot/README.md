# 项目9: AI智能管家机器人

极轻量级大模型本地部署的可移动AI家庭机器人，专注于家庭陪伴、健康监测与智能家居控制。

## 产品定位

- **隐私优先**：95%+数据本地处理，数据不出户
- **全家适配**：面部+声纹识别，自动切换老人/中年/孩子人格
- **主动关怀**：AI Agent主动决策，从提醒到确认的完整闭环
- **可移动**：全屋移动跟随，近距离交互
- **银发友好**：专为老年用户优化的交互体验

## 快速开始

### 1. 环境准备

```bash
# 创建虚拟环境
python -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 安装阿里百炼SDK
pip install dashscope
```

### 2. 配置API密钥

在 `~/.zshrc` 中添加：

```bash
export DASHSCOPE_API_KEY="your_api_key_here"
```

或在项目 `.env` 文件中配置（不推荐，会被gitignore）。

### 3. 启动前端界面

```bash
cd project9_ai_smart_butler_robot
source venv/bin/activate
python src/ui/gradio_app.py
```

访问 `http://localhost:7860` 查看界面。

### 4. 运行演示

```bash
# 用户习惯记忆演示
python demo_memory.py
```
